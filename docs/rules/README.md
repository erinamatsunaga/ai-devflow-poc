# 社内ルール置き場（フェーズ2用）

ここに社内の開発標準を Markdown で置き、AIエージェントに守らせる検証を行います。

置く想定のもの（例）:
- `coding-standards.md` — 命名規則・コーディング規約
- `branch-and-review.md` — ブランチ戦略・レビュー基準・承認者
- `commit-and-pr.md` — コミット／PRの書式
- `security.md` — 秘密情報の扱い、依存パッケージのルール
- `release.md` — リリース・デプロイ手順

置いたら `CLAUDE.md` の「社内ルール」節から参照されます。
